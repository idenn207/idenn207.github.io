TeraB

NAS에서 돌아가는 셀프호스팅 파일 관리 서비스

상태
공개 저장소 보관됨, 후속은 비공개 개발
저장소
idenn207/terab-archived (브랜치 v0.1)

개요

브라우저와 Android 앱의 요청을 Nginx가 받아 React 웹과 NestJS API로 나눕니다. 메타데이터는 PostgreSQL에, 파일은 S3 호환 MinIO에 두고, 뒤쪽 작업은 Redis와 BullMQ 워커가 맡습니다.

목표

  • 외부 클라우드 없이 NAS에서 파일을 올리고, 공유하고, 지운다.
  • 웹과 Android 앱이 같은 API를 쓴다.
  • 배포를 Docker Swarm 스택 하나로 묶는다.
  • NAS 디스크를 Windows PC의 게임 설치 공간으로 쓸 수 있는지 확인한다.

코드

마운트 자격증명의 비밀값을 파일로 저장하는 코드입니다. 이름에 경로 구분자나 ..가 있으면 쓰기 전에 거부해 저장 폴더 밖으로 나가지 못하게 하고, 파일은 0600, 폴더는 0700 권한으로 만듭니다.

역할

1인 개발입니다. 기획 문서와 ADR 작성, API와 웹, Android 앱 구성, NAS 배포를 혼자 맡았습니다.

결과

  • Windows PC에서 NAS iSCSI LUN에 Steam 게임 1종을 설치·실행, 1GbE 디스크 읽기 피크 91.8MB/s(첫 실행과 5분 플레이, 1회 관찰)
  • 웹에서 마운트 자격증명 발급·회수
  • 공개 저장소는 v0.1에서 보관하고, 후속 개발은 비공개로 이어 갑니다.
