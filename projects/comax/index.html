comax

self-host 시크릿 서버와 CLI

상태
M1~M7 구현, M8 공개 배포 미완
저장소
idenn207/comax (브랜치 master)

개요

손으로 맞추던 .env 파일을 서버 한 곳으로 모으고, 개발 PC, CI, 프로덕션 컨테이너에 암호화된 시크릿을 전달합니다.

secret CLI는 Go 1.25 이상에서 go build -o secret ./cmd/cli로 빌드해 PATH에 둡니다.

목표

  • 외부 Postgres나 Redis 없이 SQLite 파일 하나로 NAS에서 돌린다.
  • secret run 하나로 작업 위치에 맞는 환경변수를 넣는다.
  • GitHub Secret에 값마다 등록하지 않고 서비스 토큰 하나로 Actions에서 시크릿을 쓴다.
  • secret render로 설정 파일을 환경별로 채운다.

사용 기술

서버
Go 1.25, 단일 바이너리, SQLite
암호화
AES-256-GCM
화면
React 대시보드(Vite), 서버 바이너리에 내장
연동
GitHub Action, Node/TS SDK

주요 기능

단계내용상태
M1서버와 CLI, secret run구현

M3GitHub Actions 연동구현
M4웹훅, 시크릿 참조와 덮어쓰기구현

M6소개와 문서 사이트구현

M8바이너리, npm, Action 공개 배포미완

코드

GCM은 같은 키와 nonce를 다시 쓰면 안전하지 않습니다. 그래서 호출부가 nonce를 넘기지 못하게 하고, 호출마다 crypto/rand로 새로 뽑아 암호문 앞에 붙입니다.

역할

1인 개발입니다. 서버, CLI, 대시보드, SDK, 위협 모델 문서를 혼자 맡았습니다.
