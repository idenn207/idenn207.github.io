recordWEB

치지직, 유튜브, X 스페이스 라이브 자동 녹화를 NAS에서 관리하는 웹 UI

상태
개인 NAS에서 사용 중, Python에서 TypeScript로 재작성
저장소
idenn207/recordWEB (브랜치 main)

개요

채널을 등록하면 자동으로 녹화하고, 파일 정리와 YouTube 업로드까지 웹에서 처리합니다.

목표

  • 사람이 지켜보지 않아도 라이브를 녹화한다.
  • 녹화 파일을 웹에서 찾고 정리한다.
  • 기존 Python 앱의 설정 파일을 그대로 쓰면서 TypeScript로 옮긴다.

사용 기술

서버
NestJS
화면
React, Vite, Tailwind 4, Headless UI, FSD
녹화
streamlink, yt-dlp, ffmpeg를 subprocess로 실행
운영
pnpm 모노레포, Docker Compose

주요 기능

코드

녹화 도구를 라이브러리가 아닌 subprocess로 실행합니다. 명령 인자를 만드는 부분은 실행과 분리한 함수로 둡니다.

역할

1인 개발입니다. API, 화면, Docker 배포를 혼자 맡았습니다.

결과

  • Python FastAPI 앱을 NestJS + React 모노레포로 재작성
  • 설정과 상태 JSON 형식을 유지해 기존 파일을 그대로 읽음
  • 서버가 종료될 때 녹화를 멈추고 후처리를 최대 25초 기다림
  • 후처리에서 같은 이름의 파일이 있으면 덮어쓰지 않음
  • 기존 YouTube 업로드 상태 파일을 이어 받아 이미 올린 영상을 중복으로 올리지 않음
  • 재작성에서 뺀 기능: GPU 인코딩, 분할 녹화, 플러그인, 다시보기 다운로더, PyQt GUI, 앱 로그인
