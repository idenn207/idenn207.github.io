TeraB

NAS에서 돌아가는 셀프호스팅 파일 관리 서비스

TeraB 사례 보기
문제
개인 파일을 외부 클라우드에 두지 않고 NAS에서 관리하고, 게임 설치 공간으로도 쓰고 싶었습니다.
해결
NestJS API와 React 웹, Android 앱으로 파일, 공유, 휴지통, 2단계 인증을 만들고 NAS 디스크 마운트를 실험했습니다.
상태
공개 저장소 보관됨, 후속은 비공개 개발
스택
NestJS, Drizzle, PostgreSQL, MinIO, React, Docker Swarm
역할
1인 개발: 기획, 설계, 구현, 배포

recordWEB

치지직, 유튜브, X 스페이스 라이브 자동 녹화를 NAS에서 관리하는 웹 UI

recordWEB 사례 보기
문제
여러 플랫폼의 라이브를 놓치지 않고 저장하려면 방송 시작을 계속 확인해야 했습니다.
해결
채널을 등록하면 자동으로 녹화하고, 파일 정리와 YouTube 업로드까지 웹에서 처리합니다.
상태
개인 NAS에서 사용 중, Python에서 TypeScript로 재작성
스택
NestJS, React, Vite, Tailwind 4, Headless UI, FSD
역할
1인 개발: 기획, 구현, 배포

comax

self-host 시크릿 서버와 CLI

comax 사례 보기
문제
프로젝트마다 .env 파일을 손으로 맞추는 일이 반복됐습니다.
해결
Go 단일 바이너리와 SQLite로 서버를 띄우고, secret run으로 실행 명령에만 시크릿을 넣습니다.
상태
M1~M7 구현, M8 공개 배포 미완
스택
Go 1.25, SQLite, AES-256-GCM, React 대시보드, Node/TS SDK
역할
1인 개발: 기획, 설계, 구현
